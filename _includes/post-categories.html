{%- comment -%} Returns a post's front-matter categories as a '|'-joined string. Jekyll also adds every directory above a nested _posts/ folder (e.g. content/infra/file_structure) as a category; those are dropped by matching against the post's relative path. Usage: {% capture cats %}{% include post-categories.html post=post %}{% endcapture %} {%- endcomment -%} {%- assign path_dirs = include.post.relative_path | split: '/' -%} {%- assign kept = '' | split: '' -%} {%- for category in include.post.categories -%} {%- unless path_dirs contains category -%}{%- assign kept = kept | push: category -%}{%- endunless -%} {%- endfor -%} {{- kept | join: '|' -}}
